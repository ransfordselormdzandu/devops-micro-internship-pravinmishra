# Assignment Summary

Write a short summary of the completed CI/CD workflow.

In this assignment, I configured an **automated CI/CD pipeline using Azure DevOps to deploy a static website to an AWS EC2 instance**. I used Terraform to provision the EC2 infrastructure and Ansible to install and configure Nginx as the web server. I also imported the website source code into Azure Repos, configured an SSH service connection, and created a YAML pipeline using a self-hosted agent to transfer website files to `/var/www/html` and verify the deployment. The pipeline was configured to trigger automatically whenever code changes were pushed to the repository. Overall, this lab strengthened my understanding of **Infrastructure as Code (IaC), configuration management, CI/CD automation, and cloud-based website deployment**.
